# Voltra

[English](../README.md)

Локальная карта диска для macOS. Показывает папки и типы файлов, помогает найти крупные объекты и переместить выбранное в системную Корзину. Интерфейс работает в браузере, данные сканирования остаются на компьютере.

## Запуск

Нужны macOS, Node.js 22+ и Xcode Command Line Tools с компилятором `swiftc`.

```sh
git clone https://github.com/Braidner/voltra.git
cd voltra
npm ci
npm run setup
npm run build
npm start
```

Откройте [127.0.0.1:4391](http://127.0.0.1:4391), укажите `/` или абсолютный путь к папке и нажмите «Сканировать». Для разработки используйте `npm run dev`.

## Работа с картой

- Двойной клик открывает папку; путь над картой позволяет вернуться назад.
- «По типам» группирует файлы всего сканирования по расширениям.
- «Читаемые плитки» увеличивают мелкие сегменты. «Точная площадь» возвращает пропорции выделенных блоков. Числа в подписях остаются точными.
- В инспекторе можно проверить путь и добавить объект в список очистки. Перед переносом показывается весь выбранный список.
- Свёрнутые глубокие папки загружаются автоматически при входе без сброса общего обзора.

## Ограничения и безопасность

Перенос в Корзину сам по себе не освобождает место: её очистка выполняется пользователем в macOS. Приложение не удаляет безвозвратно. После переноса требуется новое сканирование.

Очистка доступна внутри домашнего каталога, кроме защищённых путей: самого домашнего каталога, Library, .ssh, .gnupg, .codex, Корзины и рабочего проекта с его предками. Остальные области доступны для просмотра. Права доступа macOS автоматически не меняются.

На карте отображаются крупнейшие объекты: до 36 основных плиток, шесть вложенных и до 80 строк в списке. В памяти сохраняются до 160 детей каждой папки и 80 крупнейших файлов каждого типа. Результаты пропадают при перезапуске сервера.

Размер считается по выделенным блокам. Hardlinks учитываются один раз; APFS clones, snapshots и purgeable space не позволяют считать сумму точным прогнозом освобождения. Недоступные каталоги и пропущенные системные области помечают результат как частичный.

## Разработка

```sh
npm run setup
npm test
npm run check
npm run build
```

Тест Корзины работает только с созданным тестовым файлом. В отчётах об ошибках используйте синтетические пути и изображения, без личных данных.
